## 4. 점검 결과 (보고서에 그대로 쓸 수 있는 수치)

| 항목 | 점검 내용 | 결과 |
|---|---|---|
| 명도 대비 | 테마 2개 × 메인 색 5개 = 10가지 조합의 모든 글자색 | 최저 **5.52 : 1** (WCAG AA 기준 4.5 : 1 통과), 다크 모드는 **7.36 : 1** 이상 |
| 색각 이상 배려 | 빨강·초록 조합 사용 여부 | 사용 안 함 (베이지 + 파랑/보라 + 주황). 모든 그래프에 선 모양·빗금·직접 라벨 |
| 화면 폭 | 320 / 375 / 768 / 1024 / 1280 px, 한국어·영어 | 가로 넘침 **없음** (점검 중 발견한 2건 수정) |
| 대체 텍스트 | 이미지 alt, 그래프(canvas) 설명, 아이콘 버튼 이름 | 빠진 것 **없음**, 영어 모드에서는 영어로 바뀜 |
| 제목 구조 | 페이지마다 h1 하나, 단계 건너뛰기 | 모두 통과 (점검 중 발견한 단원 페이지 1건 수정) |
| 키보드 | 본문 바로가기, 서랍 Esc로 닫기, 포커스 표시, 슬라이더 방향키 | 지원 |
| 화면 읽기 프로그램 | 슬라이더를 놓으면 현재 값과 결과를 한 문장으로 읽어 줌 | 지원 (aria-live) |
| 움직임 | 자동 재생은 ▶ 버튼을 눌렀을 때만 | 저절로 움직이는 화면 없음 |
| 서버 없이 열기 | `fetch`·모듈 사용 여부, 절대 경로 | 사용 안 함 → `index.html` 더블클릭으로 열림 (수식·글꼴은 인터넷 필요) |

### 점검하면서 고친 것
1. 폭 320px 폰과 375px 영어 모드에서 **헤더(사이트 이름 + 학교 로고)가 화면보다 넓어지던 문제** → 사이트 이름 두 줄 허용, 로고 크기 축소
2. 320px 영어 모드에서 **놀이터 기호 사전 표가 넘치던 문제** → 긴 단어 줄바꿈
3. 단원 페이지의 **제목 단계가 h1 → h3로 건너뛰던 문제** → 화면 읽기용 h2 "중단원 목록" 추가
4. 일부 영역 이름(aria-label)이 **한국어로만 되어 있던 문제** → 영어 모드에서 영어로 바뀌게 수정
